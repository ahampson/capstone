## How it works

The visitor provide a name for the in game "hero" and selects an ability from a list of options. When the create button is pressed, the name, ability, and parsonality trait are saved to browsers local storage. The play is then presented with the profile page and is given a description of the new hero's backstory. The Profile page shows the statstics for the two activitys in the site.
